01

Definitions

The core vocabulary used everywhere below — refer back here while working through examples and exercises.

Degree of a vertex

deg(v) is the number of edges incident to v. A loop at v is counted twice.

deg(v) = edges touching v

Handshake lemma

Summing every vertex's degree counts each edge exactly twice (once per endpoint).

Σ deg(v) = 2·|E|

Degree sequence

The list of all vertex degrees, usually written in non-increasing order — e.g. (3, 2, 2, 1).

Minimum / maximum degree

δ(G) is the smallest degree in the graph, Δ(G) the largest. Every degree lies between them.

Regular graph

G is k-regular if every vertex has degree exactly k. Then |E| = nk / 2.

Isolated & pendant vertices

deg(v) = 0 → isolated vertex (no connections). deg(v) = 1 → pendant vertex, or leaf.

In-degree / out-degree (digraphs)

In a directed graph, deg⁺(v) counts edges leaving v and deg⁻(v) counts edges entering v.

Σ deg⁺(v) = Σ deg⁻(v) = |E|

Odd-degree corollary

Since Σ deg(v) is always even, the number of vertices with odd degree in any graph is always even.

02

Worked examples

Example 1 — a simple graph

  1. List edges: A–B, A–C, B–C, B–D, C–E
  2. Count how many of these touch each vertex
deg(A)=2, deg(B)=3, deg(C)=3, deg(D)=1, deg(E)=1.
Degree sequence: (3, 3, 2, 1, 1). Sum = 10 = 2×5, matching |E| = 5. D and E are pendant vertices.

Example 2 — a loop

  1. Edges: P–Q, P–R, Q–R, and a loop at Q
  2. The loop contributes 2 to deg(Q), not 1
deg(P)=2, deg(Q)=2+2=4, deg(R)=2.
Degree sequence: (4, 2, 2). Sum = 8 = 2×4, matching |E| = 4 (3 ordinary edges + 1 loop).

Example 3 — a regular graph

  1. Every vertex connects to all three others: this is K₄
  2. Each vertex has the same degree
deg(1)=deg(2)=deg(3)=deg(4)=3. K₄ is 3-regular.
Check: |E| = nk/2 = 4×3/2 = 6, which matches the 6 edges drawn.

03

Experiments & activities

  • Handshake pairing. Without drawing anything: every edge has exactly two ends, so if you listed every vertex's degree and added them up, each edge gets counted once at each end. That's why the total is always even — try to construct a degree sequence with an odd sum in the tool and see why you can't ever finish it.
  • Build to a target. Pick a degree sequence such as (3, 3, 2, 2) and try to build a graph matching it in the interactive tool. Then try (3, 3, 3, 1) — does it work? Compare what makes one sequence achievable and the other not.
  • Find the regular graphs. Using presets or manual edges, build a 2-regular graph on 5 vertices, then a 3-regular graph on 6 vertices. For each, verify |E| = nk/2 using the live stats panel.
  • Trees and leaves. Build a tree (a connected graph with no cycles) on 6 vertices. Confirm it has exactly 5 edges, that Σdeg(v) = 10, and count how many pendant vertices (leaves) it has.
  • Networks around you. Model a small network you know — a group chat, a set of linked devices, a communication network — as a graph, with a vertex per member and an edge per direct link. Build it in the tool and identify which vertex has the highest degree (the most direct connections) and which is isolated, if any.

05

Exercise problems

Fill in every answer below in the stated format, then submit all 8 at once for a score out of 8.

1. A graph has 6 edges. What is Σ deg(v) over all its vertices?

Format: a single whole number.

By the handshake lemma, Σ deg(v) = 2|E| = 2×6 = 12.

2. Is (1, 1, 1) a valid degree sequence for some graph?

Format: type "yes" or "no".

No. Its sum is 3, which is odd — impossible for any graph, since Σ deg(v) must always be even.

3. A tree has 9 vertices. How many edges does it have, and what is Σ deg(v)?

Format: two whole numbers, one per box.

A tree on n vertices has n − 1 edges, so 8 edges. By the handshake lemma, Σ deg(v) = 2×8 = 16.

4. Build a 4-regular graph on 5 vertices in the tool. How many edges does it have — and what is this graph normally called?

Format: a whole number for the edge count, and a short name (e.g. "K5") for the graph.

|E| = nk/2 = 5×4/2 = 10 edges. Every pair of the 5 vertices is connected — that's the complete graph K₅.

5. A graph has degree sequence (4, 3, 3, 2, 2, 2). Verify the handshake lemma is consistent with this sequence, and give |E|.

Format: a single whole number for |E|.

Sum = 4+3+3+2+2+2 = 16, which is even, so it's consistent. |E| = 16/2 = 8 edges (this alone confirms consistency, not that a graph with this exact sequence necessarily exists).

6. In a directed graph modelling one-way links, Σ deg⁺(v) = 15. What is Σ deg⁻(v), and how many edges are there?

Format: two whole numbers, one per box.

Σ deg⁻(v) = Σ deg⁺(v) = 15, and |E| = 15 (each directed edge contributes exactly one out-degree and one in-degree).

7. A graph has 5 vertices, all of degree 2. Name the type of graph this must be.

Format: a short name — e.g. "C5" or "cycle".

It's a 2-regular graph on 5 vertices — a single cycle, C₅ (five vertices connected in a ring). Try the "Cycle C₅" preset in the tool to see it.

8. True or false: a graph can have exactly one vertex of odd degree.

Format: type "true" or "false".

False. The number of odd-degree vertices in any graph is always even, since Σ deg(v) = 2|E| is even and each even-degree vertex contributes an even amount to that sum.
